# 验证范围

- 实机：iStoreOS 24.10.8、Linux 6.6.144、x86_64、Docker 27.3.1、Compose 2.39.1。
- USB：ESXi 直通 DJI EG25G-QDC507，`2ca3:4006`。
- DJI 补丁：新增前的测试失败，修补后发现/串口选择测试通过；真实容器能够发现模块并读取 AT 身份信息。
- LuCI：实际页面的启动/停止、运行状态和打开链接已验证。
- 端口设置：前端输入校验；后端固定命令与整数边界；运行/关闭状态转换；TCP 端口占用；应用失败回退；IPK 布局和执行权限均有自动化检查。

持续集成同时构建 amd64、arm64 镜像，并在 amd64 上检查实际 HTTP `/ping`。ARM64 目前不代表已在 ARM 路由器实测。

未验证：所有型号的 eUICC 下载、语音/IMS、USB 网络模式切换、真实断电和固件升级后的数据保留。DJI 驱动规则通过脚本和已有硬件绑定测试，完整重启枚举需按使用者环境验收。
